# 应用码：在圆屏上亮码

圆屏上亮一圈声波一样的码，用户用 Tikpal App 的「扫一扫」一扫，App 就打开你这个应用的页面（有小程序就开小程序，没装就去商城里它的页面）。码里只有三样：**应用编号**、**动作**、**值**。不经过服务器，也不会过期。

接口级别 4 起有（`./kit version` 的 `apiLevel`）。最低主固件写在那一版开发包的 `devkit.json` 里。

## 1. 先写 app.json

```json
"voiceCode": {
  "number": 65280
}
```

- `number`：在开发者平台建应用时当场给你的应用编号。还没建应用就先写本机测试号（65280–65535 里随便一个，模板写的是 65280），只能在自己的圆屏上试，App 扫到只开一个调试页、不进商城；**提交前换成正式编号**。
- 编号**不用在代码里写**：构建时从 `app.json` 读出来编进镜像。改了号要重编。
- 这一版 `voiceCode` 只写 `number`，详见 [app-json.md 的「应用码 voiceCode」](app-json.md#应用码-voicecode)。

## 2. CMake

Tikpal 主固件 0.1.14（开发包 1.9）起，`yaykit_voicecode` 默认链接：`yaykit_app` 依赖它，组件目录由 `firmware/reproducible.cmake` 加上，`CMakeLists.txt` 的 `EXTRA_COMPONENT_DIRS` 不用再加，老应用的 CMake 也不用改。系统下拉里的码重编就有。

只有你自己的代码要调 `yk_vc_show()`，才在 `main/CMakeLists.txt` 的 `REQUIRES` 加 `yaykit_voicecode`（要用它的头文件）。模板（`./kit new`）已经加好了。

## 3. 亮码

```c
#include "yk_vc_view.h"

// 应用页（动作 0，值 0）：先跳 1.2 秒再停住，60 秒或点一下、滑一下就收起
yk_vc_show(YK_VC_ACTION_PAGE, 0, NULL);

// 某一天的记录，亮 5 分钟，收起时告诉你
yk_vc_show(YK_VC_ACTION_DAY, days_since_1970, &(yk_vc_show_opts_t){.hide_after_s = 300, .on_hidden = gone});

// 在 yk_app_on_key() 的回调里：码亮着时短按侧键收起它
if (yk_vc_on_key(ev)) return true;
```

- `yk_vc_show(动作, 值, &opts)`：盖在你的屏幕上，纯黑底，码在中间。竖条先像说话一样跳，停住以后 App 才认得出，停住了长短不会再变。
  - 返回 `ESP_ERR_NOT_SUPPORTED`：`app.json` 没写 `voiceCode`；`ESP_ERR_INVALID_ARG`：动作或值超出范围。
  - 已经亮着一个码，新的接着它跳到新码上，旧的收到 `YK_VC_HIDDEN_REPLACED`。
- 收起：60 秒到了（`opts.hide_after_s` 改，小于 0 是一直亮）、点一下码、在码上往任何方向滑一下（滑动归码，不传给你的页面；`opts.keep_on_tap` 两样都不收）、`yk_vc_on_key()`、`yk_vc_hide()`。`opts.on_hidden` 告诉你是哪种。
- `yk_vc_showing()`、`yk_vc_settled()`：现在亮没亮、停没停。
- 哪个任务都能调，函数自己拿 `board_lock()`（是递归锁）。
- **屏幕要你自己保持亮着**：熄屏默认 30 秒，比码收起早。亮码时 `yk_app_keep_screen_on(true)`，收起时（`on_hidden` 里）改回来。组件不碰这个开关。
- 内存：码的状态约 1 KB，在 PSRAM，亮的时候才有。

模板里就是这样做的：屏幕下面「在手机上打开」按一下亮动作 0 的码；码亮着屏幕不熄，短按侧键或点码收起（`firmware/_template/main/main.c` 的 `on_code`）。这个码系统下拉里也有（第 5 节），模板放这个按钮是给你看怎么亮码，用不上就删掉。

## 4. 三个通用动作

| 动作 | 常量 | 值 | 扫了打开什么 |
|---|---|---|---|
| 0 | `YK_VC_ACTION_PAGE` | 0 | 应用页（有小程序就开小程序） |
| 1 | `YK_VC_ACTION_SERVICE` | 0 | 整页服务页 |
| 2 | `YK_VC_ACTION_DAY` | 1970-01-01 起的天数（圆屏本地日期） | 那一天的记录 |

- 这一版只用这三个动作。别的动作 App 一律打开应用页，值也不带过去。
- 值最多 24 位（0–16777215）。

## 5. 系统替你亮的码

- 圆屏**从顶边往下拉**是系统的下拉，放 Wi-Fi、手机连接这些状态。`app.json` 的 `voiceCode` 开发包 1.9 起必填，`yaykit_voicecode` 跟着 `yaykit_app` 自动链上，下拉里就有「在手机上打开」，点了全屏亮动作 0 的码。你不用写，重编就有。
- 所以别在屏幕最上面那一条做往下拉的手势：从顶边往下拉是系统的。别处往下滑照旧是你的。
- **应用环只放应用**：双击侧键出的环只管换应用、回 Tikpal，不亮码。

## 6. 码长什么样

纯黑底上的亮线，尺寸都按外圈半径 R 算（圆屏上 R = 184 px）：

- 外圈细圆，粗 0.02R；12 点方向 0.88R 处一个珊瑚色方向点；
- 48 根圆头竖条，宽 0.03R，中点都在 0.64R 的圆上、指向圆心，长度 `0.08 + 0.07 × 档`（档 0–3）；
- 中间 0.40R 以内是 Tikpal 标，不带信息。颜色也不带信息，App 只看亮度。

码里是 6 个字节的数据加 6 个 Reed-Solomon 校验字节：遮住、反光坏掉几根也认得出。格式是 Tikpal 自己定的，**不用自己编码**：调 `yk_vc_show()` 就对。

样例（档从 12 点右边第一根起顺时针，48 根）：

| 应用编号 | 动作 | 值 | 48 根竖条的档 |
|---|---|---|---|
| 1 | 0 | 0 | `122330020213213212102221021232022321330112011302` |
| 7 | 1 | 0 | `122330021012213212102221000312031313322023032302` |
| 300 | 2 | 20756 | `122331003311213203112331030002011330030000001013` |
| 42 | 3 | 2 | `122330002110213212102223330022301030001101000221` |
| 65535 | 15 | 16777215 | `121003313020120121231112110230221223333121233222` |

这几条就是 Tikpal 自己的合同样例，组件和这一页都对着它逐字核过。

## 7. 自测

- 在自己的圆屏上：`./kit install --slot 2` 以后亮码，`./kit snap` 截图看码在不在中间、停没停；用 Tikpal App 的扫一扫扫它（测试号打开调试页）。
- 亮码的时候看 `./kit logs`：`YK_VC show app <编号> action <动作> value <值>`，停住时 `YK_VC settled levels=<48 档>`，收起时 `YK_VC hidden why=<…>`。
- 检查清单（[checklist.md](checklist.md)）的「应用码」一节。
